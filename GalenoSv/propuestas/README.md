# Propuestas visuales de bienvenida

Estas propuestas son mockups estaticos para decidir la direccion visual de la pagina de bienvenida de GalenoSv como si el sistema ya estuviera completo.

- `propuesta-1-clinica-operativa.html`: bienvenida sobria, orientada a gestion diaria de la clinica.
- `propuesta-2-paciente-cercano.html`: bienvenida mas humana, orientada al recorrido del paciente.
- `propuesta-3-panel-control.html`: bienvenida tipo tablero administrativo completo.
- `index.html` y `estilo.css`: version separada de la propuesta 2 seleccionada.

Se pueden abrir directamente en el navegador. Son propuestas visuales para escoger la bienvenida antes de integrarla al sistema.
